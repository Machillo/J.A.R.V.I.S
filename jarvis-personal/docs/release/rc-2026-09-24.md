## 4. Physical test checklist

Build Android with `npm run android:apk` (set `GOOGLE_SERVICES_JSON` and, for the PostHog test, `VITE_POSTHOG_KEY`/`HOST`). Build iOS with `npm run ios:sync`, then an Xcode archive/run. Use disposable test accounts. Record the device, OS, build and result for each line.

### Android (Free, Basic, VIP + Owner)
- [ ] **Login and logout.**
  - Google login from a cold start, then `/auth/me` returns 200 (#214).
  - Still signed in after more than 1 h (token refresh).
  - Logout from the menu, and logout from the app-lock screen.
  - With a pending offline change: the confirmation appears in ES and EN, and nothing is lost if you cancel (#217).
- [ ] **Plans.** Free, Basic and VIP each show their own screens. Owner opens after the boot screen, and its charts render (lazy chunk, #215). A User never sees Owner.
- [ ] **Gmail (VIP).**
  - Connect → first sync. Candidates show **correct amounts**: especially `₡15.000`-style values without decimals, and USD (#211).
  - Accept, correct and reject each work. An accepted item appears in Movimientos exactly once.
  - Disconnect.
- [ ] **Outlook (VIP).** Connect, sync, accept one candidate. The OAuth return comes back to the app, including after a cold start.
- [ ] **Movimientos.** Add an income and an expense with a **rapid double tap** on "Guardar": exactly one record each (#218). Edit one, delete one.
- [ ] **Debts, goals, savings, recurring.** Same double-tap check. Register a debt payment and a goal contribution.
- [ ] **Strategy.** Basic and VIP screens load. Numbers are identical in ES and EN, and nothing is negative or impossible.
- [ ] **Offline and retry.**
  - Airplane mode → add an expense → back online → exactly one record.
  - API unreachable → a clear message, never an infinite spinner.
- [ ] **Lifecycle.** Background during a save, then resume. Cold start and warm start. Android back button inside sheets and dialogs.
- [ ] **UI.** Keyboard covers no inputs (support chat, forms). Safe areas and gesture navigation. Largest system font. TalkBack on Login, Overview, Movimientos, Gmail review and Support (#216).
- [ ] **PostHog** (build with the key, after the gates in §3.6):
  - live events arrive: `app_opened`, then `screen_viewed` (screen=transactions), then `app_resumed`;
  - properties are only plan, platform, app_version and screen, plus token, distinct_id and the two `$` flags;
  - no new Persons appear;
  - Owner and non-accepted accounts send nothing;
  - Gmail connect produces one `gmail_connected` and no `mail_connected` (#210).
- [ ] **Account deletion.**
  - Export data first: the file does not include OAuth flow internals.
  - Delete a disposable VIP account that has a CCSS order imported, then try to log in again. It must be a fresh Free account with no old data (#217, #221).
- [ ] **Firebase.** An APK built **without** `google-services.json` starts without crashing (#208).
