# Logos en el selector de instituciones

Los logos identifican las entidades que el usuario selecciona para personalizar
su perfil. No representan convenio bancario ni conexión con una entidad.

- `bac.svg`: sitio de BAC Credomatic (`baccredomatic.com/themes/custom/bac_theme/images/bac_logo.svg`).
- `multimoney.svg`: sitio de MultiMoney Costa Rica (`nextgen-mmcr.cdn.prismic.io`, imagen de cabecera). `multimoney.png` es una copia rasterizada local para la aplicación.
- `popular.svg`: sitio de Banco Popular (`bancopopular.fi.cr/wp-content/themes/bp/assets/img/bp-logo.svg`). `popular.png` es una copia rasterizada local.
- `promerica.png`: sitio de Banco Promerica Costa Rica (`promerica.fi.cr/media/bswp0fi5/crm-logo-1.png`).
- `bn.png`: Wikimedia Commons, archivo `Banco Nacional de Costa Rica.png`.
- `bcr.png`: versión local del archivo `LOGO BCR.svg` de Wikimedia Commons.
- `davivienda.png`: Wikimedia Commons, archivo `Davivienda Logo.png`.
- `davibank.png`: versión local del logo del sitio de DAVIbank Costa Rica (`cdn.aglty.io/scotiabank-costa-rica/2019-global-rebrand/Davibank-logo_20251202083759.svg`). El id `scotiabank` se conserva para los perfiles existentes.
- `gmail.png`: ícono Gmail de `ssl.gstatic.com/ui/v1/icons/mail/rfr/gmail.ico`, convertido a PNG.
- `outlook.svg`: ícono Outlook del CDN de Microsoft 365 (`res-1.cdn.office.net`, `outlook_48x1.svg`).

Las marcas pertenecen a sus respectivos titulares; los archivos se usan solo
para identificar servicios al usuario. Revisar cambios de identidad antes de
actualizarlos y mantener el nombre de la institución como texto accesible.
